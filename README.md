# 🦊 FoxxForge - MTG Duplicate Checker

A lightweight tool built to analyze Magic: The Gathering collections and detect duplicated cards across decks.

Created as a personal project to improve collection management, deck organization and automation workflows for MTG players.

---

## ⚒️ Features

- Detect duplicate cards between decks
- Analyze exported deck lists
- Fast and lightweight
- Simple and readable output
- Built for scalability and future improvements

---

## 🌱 Current Goals

- Improve deck parsing
- Add support for multiple formats
- Export results automatically
- Web interface prototype
- API integration with deck platforms
